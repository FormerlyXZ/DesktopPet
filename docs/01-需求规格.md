# 需求规格

## 1. 桌宠本体

### 1.1 窗口行为
- 始终置顶（漂浮在其他窗口之上）
- 无边框透明窗口
- 人物区域正常响应鼠标，透明区域点击穿透到后方窗口
- 9:16比例，高度可调节，宽度自动计算

### 1.2 初始状态
- 默认高度：500px（2K屏幕适配）
- 默认位置：屏幕右下角
- 显示第一帧作为待机状态

### 1.3 角色系统
支持两种角色类型，可在设置中切换：

| 角色 | 类型 | 说明 |
|------|------|------|
| 默认服装 | PNG 帧序列 | 现有角色，待机/悬停两种动画槽位 |
| Q版高木同学 | GIF 动图 | 新增角色，36个动图，丰富交互系统 |

### 1.4 PNG 动画播放（默认服装）
- 帧序列按顺序播放，支持循环
- 每个动画预设时长5秒，自动计算帧间隔
- 动画类型：待机、挥手等（按文件夹组织）

### 1.5 GIF 动画播放（Q版）
- 使用 QMovie 原生播放，遵循 GIF 自身帧间隔
- 支持循环（待机）和单次播放（交互反应）
- 启动序列：到达 → 加载 → 加油（默认，可自定义）

### 1.6 鼠标交互

#### 默认服装
| 操作 | 行为 |
|------|------|
| 鼠标悬停在人物上 | 播放悬停动画（循环） |
| 鼠标离开人物 | 回到待机状态 |
| 点击人物 | 弹出气泡面板 |
| 按住拖拽 | 移动到指定位置 |

#### Q版高木同学
| 操作 | 行为 |
|------|------|
| 鼠标悬停 | 播放"害羞"GIF |
| 悬停3秒 | 播放"问号"GIF |
| 单击 | 播放"惊吓"GIF |
| 双击（400ms内） | 播放"生气"→"哭"GIF（链式） |
| 点击面板按钮 | 播放"点头"GIF |
| 设置关闭/不保存 | 播放"摇头"GIF |
| 按住拖拽 | 移动到指定位置 |

## 2. 气泡面板

### 2.1 外观
- 在人物旁边弹出
- 淡蓝色主题，简洁风格
- 点击面板外区域自动收起

### 2.2 功能入口
| 入口 | 状态 |
|------|------|
| 设置 | 可用 |
| 历史粘贴板 | 预留，灰色不可用 |
| 退出 | 可用 |

## 3. 设置窗口

### 3.1 通用设置
- 角色选择（默认服装 / Q版高木同学）
- 大小调节滑块 + 数字输入
- 开机自启开关

### 3.2 默认服装设置（PNG页）
- 待机动画选择下拉框
- 悬停动画选择下拉框

### 3.3 Q版设置（GIF页）
- 启动序列编辑器（可增删改序）
- 行为检测映射：打字/音频播放/静音 各对应下拉框
- 鼠标交互映射：悬停/长悬停/单击/双击第一步/双击第二步/面板按钮/关闭放弃 各对应下拉框
- AFK设置：空闲超时秒数、随机间隔范围、可用动画多选池

## 4. Q版行为检测

| 检测条件 | 触发动画 | 实现方式 |
|---------|---------|---------|
| 用户按下任意键 | 打字 | pynput 全局键盘监听 |
| 系统正在播放音频 | 唱歌 | Windows Core Audio API |
| 系统静音 | 静音 | Windows Core Audio API |

## 5. Q版 AFK 随机系统
- 30秒无键盘/鼠标操作后开始触发
- 之后每隔 1-3 分钟从可用动画池中随机播放一个
- 恢复操作后停止

## 6. 扩展预留
- 服装切换系统（不同服装=不同帧动画目录）
- 历史粘贴板功能模块

## 7. 配置持久化
- 保存：角色类型、窗口大小、位置、动画设置、Q版各项映射和序列
- 格式：JSON配置文件
- 位置：程序目录下的 config.json
- 支持旧版 config 平滑升级（deep_merge）
