## 2. 气泡面板（左键功能面板 / 右键系统面板）

> 2026-09-10 重写：**全自绘**（不再用 QSS 文字列表），与悬停菜单/养成面板同一套笔触。

```
┌────────────────────────┐
│                    (✕) │  ← 28px 圆形关闭按钮
│  (📋)  历史粘贴板       │  ← 行胶囊：30px 圆形矢量图标 + 13px 文字
│  (📌)  窗口置顶      (✓)│  ← 可勾选项右侧 16px 圆形指示，选中 = 粉底 + 暖棕勾
└────────────────────────┘
   奶白纸片 + 2px 暖棕描边 + 20px 圆角 + 暖色投影
```

| 项 | 规格 |
|----|------|
| 可见宽度 | 按最长文案自算，夹在 `[168, 216]` px（比旧的固定 170px 更贴内容） |
| 窗口 | 可见面板 + 四边各 `MARGIN=6px`（留给投影） |
| 内边距 | 10px |
| 行高 / 行距 | 36px / 4px（行高比圆形图标高 6px，让 hover 胶囊的描边与图标圆留出间隙） |
| 图标 | 30px 正圆（底 `#FFF1EC` + 2px 暖棕描边）内嵌 18px 矢量图标 |
| 默认态 | 行底透明；Hover = 粉浅底 + 粉描边；按下 = 粉深底 |
| 选中态（checkable） | 粉浅底 + 藏青粗体文字 + 右下圆形勾 |
| 关闭 | 28px 圆形按钮（Hover 时带 3px 粉色光圈） |
| 圆角 | 20px，四角半径差 ≤2px（手绘感，见规范第 3 节） |

### 2.1 定位规则

面板采用两种定位方式（**间距一律指"看得见的面板边缘"，不是窗口边缘**）：

| 触发 | 方法 | 锚点 | 说明 |
|------|------|------|------|
| 左键功能面板 / 设置窗口 | `popup_at(pet_geometry)` | 人物 | 默认靠在人物右侧，空间不足时翻转到左侧 |
| 右键系统面板 | `show_at(cursor)` | 光标 | 面板**一角对准鼠标**（类系统菜单） |

**右键系统面板一角对准鼠标**（对齐 Windows / 常见软件习惯）：

```
光标在右下方空间充足时（默认）       光标在右侧贴近屏幕边缘时（左翻）
        ┌──────────────┐
        │ ▢  置顶        │       ┌──────────────┐
    ▣→ │   桌面层级      │       │   桌面层级     │◄▣
        │   最小化到托盘  │       │   设置         │
        └──────────────┘       └──────────────┘
        （左上角对准光标）          （右上角对准光标）
```

- 默认：面板**左上角**对准鼠标
- 面板超出右边界 → 翻转到鼠标**左侧**（右上角对准鼠标）
- 面板超出下边界 → 翻转到鼠标**上方**（左下角对准鼠标）
- 两轴同时翻转 → 鼠标位于面板**右下角**
- 极端越界时夹紧到屏幕可用区域
- 优先使用**光标所在屏幕**（支持多显示器）

> 注：该定位仅作用于右键系统面板。左键功能面板与设置窗口仍以人物为锚点（见第 2 节）。

## 3. 设置窗口

> 2026-09-10 重写：外壳自绘（奶白纸片 + 2px 暖棕描边 + 20px 圆角 + 暖色投影），
> 分区改成**纸片小卡**（`QGroupBox`：`#FFF1EC` 底 + 1.5px `#C9AFA6` 描边 + 12px 圆角
> + 藏青粗体标题），标准控件由 `ui_theme.app_stylesheet()` 上色。
> **文案里的 emoji 前缀全部去掉**（分组标题已经是藏青粗体的纸片标题，再加 emoji 会变成"图标配 emoji"）。

### 3.1 通用布局
- 可见纸片：**420×640**（窗口 = 可见 + 四边各 6px 投影留白）
- 内边距：16px（水平）/ 8px（上）/ 14px（下）
- 圆角：20px（四角不等，手绘感）
- 无边框 + 半透明奶白底（`rgba(255,249,246,242)`）+ 暖色投影
- 角色选择下拉框位于顶部，控制下方 QStackedWidget 页面切换
- 底部：`保存并退出`（粉底主按钮）+ `关闭`（奶白次按钮）

## 4. 交互规范
- 面板弹出/收起：220ms/180ms 滑入淡出动画
- 按钮hover：背景色过渡150ms
- 拖拽：实时跟随鼠标，无延迟
- 滑块调节大小时：实时更新桌宠大小
- 角色切换时：QStackedWidget 立即切换，设置实时同步

## 5. 字体
- 中文：Microsoft YaHei（微软雅黑）
- 大小：标题15px，正文13px，说明12px
