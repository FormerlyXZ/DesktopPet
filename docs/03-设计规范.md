# UI设计规范

## 1. 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#E3F2FD` | 淡蓝底色（面板/窗口背景） |
| 主色深 | `#BBDEFB` | 按钮hover、选中态 |
| 强调色 | `#42A5F5` | 按钮、滑块、开关等交互元素 |
| 强调深 | `#1E88E5` | 按钮hover、按下态 |
| 文字主 | `#212121` | 标题、正文 |
| 文字次 | `#757575` | 说明文字、预留入口 |
| 分隔线 | `#E0E0E0` | 列表分隔、边框 |

## 2. 气泡面板

```
┌──────────────────┐
│  ⚙  设置          │  ← hover时背景变 #BBDEFB
│  📋 历史粘贴板    │  ← 灰色文字 #757575
│  🚪 退出          │
└──────────────────┘
```

- 宽度：170px（代码中 `setFixedWidth(170)`）
- 内边距：8px
- 每项高度：40px
- 圆角：12px（`paintEvent` 中 `drawRoundedRect`）
- 半透明磨砂玻璃背景：填充 `rgba(227,242,253,228)`，描边 `rgba(187,222,251,160)`

### 2.1 定位规则

面板采用两种定位方式：

| 触发 | 方法 | 锚点 | 说明 |
|------|------|------|------|
| 左键功能面板 / 设置窗口 | `popup_at(pet_geometry)` | 人物 | 默认靠在人物右侧，空间不足时翻转到左侧 |
| 右键系统面板 | `show_at(cursor)` | 光标 | 面板**一角对准鼠标**（类系统菜单） |

**右键系统面板一角对准鼠标**（对齐 Windows / 常见软件习惯）：

```
光标在右下方空间充足时（默认）       光标在右侧贴近屏幕边缘时（左翻）
        ┌──────────────┐
        │ ▢  置顶        │       ┌──────────────┐
    ▣→ │   桌面层级      │       │   桌面层级     │◄▣
        │   最小化到托盘  │       │   设置         │
        └──────────────┘       └──────────────┘
        （左上角对准光标）          （右上角对准光标）
```

- 默认：面板**左上角**对准鼠标
- 面板超出右边界 → 翻转到鼠标**左侧**（右上角对准鼠标）
- 面板超出下边界 → 翻转到鼠标**上方**（左下角对准鼠标）
- 两轴同时翻转 → 鼠标位于面板**右下角**
- 极端越界时夹紧到屏幕可用区域
- 优先使用**光标所在屏幕**（支持多显示器）

> 注：该定位仅作用于右键系统面板。左键功能面板与设置窗口仍以人物为锚点（见第 2 节）。

## 3. 设置窗口

### 3.1 通用布局
- 窗口大小：380×550（Q版内容较多，需更大空间）
- 内边距：18px
- 圆角：12px
- 无边框，半透明磨砂玻璃背景
- 角色选择下拉框位于顶部，控制下方 QStackedWidget 页面切换

## 4. 交互规范
- 面板弹出/收起：220ms/180ms 滑入淡出动画
- 按钮hover：背景色过渡150ms
- 拖拽：实时跟随鼠标，无延迟
- 滑块调节大小时：实时更新桌宠大小
- 角色切换时：QStackedWidget 立即切换，设置实时同步

## 5. 字体
- 中文：Microsoft YaHei（微软雅黑）
- 大小：标题15px，正文13px，说明12px
