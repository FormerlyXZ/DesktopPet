# 技术方案

## 1. 技术选型

| 层级 | 选择 | 理由 |
|------|------|------|
| 语言 | Python 3.10+ | 快速开发，生态丰富 |
| GUI框架 | PySide6 | Qt的Python绑定，成熟稳定，原生Windows支持好 |
| GIF播放 | QMovie | PySide6原生，自动处理帧间隔，无需PIL |
| 键盘监听 | pynput | 跨平台，纯Python，API简洁 |
| 音频检测 | ctypes + Windows Core Audio API | 零额外依赖，直接调用系统COM接口 |
| 打包 | PyInstaller | 将Python程序打包为单个.exe |
| 配置存储 | JSON文件 | 简单直接，无需数据库 |

## 2. 架构设计（策略模式）

```
main.py
  ├── PetWindow (QLabel)              # 主窗口：透明无边框置顶
  │     └── CharacterController        # 抽象角色接口
  │           ├── PngCharacter         #  包装 AnimationEngine（默认服装）
  │           └── GifCharacter         #  包装 QMovie + 状态机（Q版）
  ├── BubblePanel                      # 气泡面板
  ├── SettingsWindow                   # 设置窗口
  │     └── QStackedWidget
  │           ├── PNG 设置页           #  待机/悬停下拉框
  │           └── GifSettingsPage      #  Q版全部设置
  ├── InputMonitor (QThread)           # pynput 全局输入监听
  ├── AudioMonitor (QTimer)            # ctypes 音频检测
  └── Config                           # JSON 配置读写
```

**设计原则**：PNG 和 GIF 两套系统通过统一的 `CharacterController` 抽象接口共存，PetWindow 不直接操作动画引擎。新增 GIF 系统不改动任何 PNG 相关代码。

## 3. CharacterController 抽象接口

```python
class CharacterController(QObject):
    # 信号
    frame_changed = Signal(QPixmap)       # 帧更新（用于mask）
    interaction_finished = Signal()        # 单次GIF播放完毕

    # 生命周期
    start() -> None
    stop() -> None
    get_current_pixmap() -> QPixmap

    # 交互接口（PngCharacter 实现为空操作或简单映射）
    handle_mouse_enter() -> None
    handle_mouse_leave() -> None
    handle_single_click() -> None
    handle_double_click() -> None
    handle_panel_button_clicked() -> None
    handle_settings_close() -> None
    handle_settings_discard() -> None
    handle_key_press() -> None
    handle_audio_playing() -> None
    handle_audio_muted() -> None
    reset_afk() -> None
```

## 4. 关键技术点

### 4.1 透明窗口 + 区域穿透
- `setAttribute(Qt.WA_TranslucentBackground)` 实现透明背景
- `setWindowFlags(Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint | Qt.Tool)` 无边框置顶
- 使用 `setMask()` 根据当前帧的非透明像素设置有效区域

### 4.2 PNG 帧动画播放（默认服装）
- 使用 QTimer 控制帧切换
- 帧间隔 = 5000ms / 帧总数（每动画5秒）
- 悬停时循环播放，离开后回到第一帧

### 4.3 GIF 动画播放（Q版）
- 使用 QMovie 直接加载 GIF 文件
- QMovie.CacheAll 缓存所有帧到内存，消除磁盘IO卡顿
- frameChanged 信号连接 setMask() 更新透明区域
- finished 信号判断单次GIF播放完毕
- 循环播放：finished → start()（UniqueConnection 防重复）
- 单实例 QMovie，通过 setFileName() 切换文件

### 4.4 拖拽移动
- 重写 mousePressEvent / mouseMoveEvent / mouseReleaseEvent
- 通过移动距离区分拖拽和点击（阈值：5像素）
- Q版额外区分单击和双击（400ms延迟确认）

### 4.5 气泡面板定位
- 计算 PetWindow 中心位置
- 气泡面板偏移显示在人物左侧或右侧（根据屏幕空间自动选择）
- **左键功能面板 / 设置窗口**（`popup_at(pet_geometry)`）：以人物为锚点定位，默认靠在人物右侧，屏幕空间不足时翻转到左侧
- **右键系统面板**（`show_at(cursor)`）：在光标处弹出，遵循"面板一角对准鼠标"的类系统菜单规则：
  1. 默认让面板**左上角**对准光标；
  2. 面板超出屏幕右边界 → 整体翻转到光标**左侧**（右上角对准光标）；
  3. 面板超出屏幕下边界 → 整体翻转到光标**上方**（左下角对准光标）；
  4. 两轴同时翻转时，光标位于面板**右下角**；
  5. 极端情况下仍越界 → 夹紧到该屏幕可用区域内。
  - 优先使用**光标所在屏幕**（`app.screenAt(pos)`），支持多显示器，避免在副屏弹出错位
  - 无动画，`_popup_direction = "none"`，隐藏时直接消失（`hide_with_anim` 跳过滑出动画）

### 4.6 面板过渡动画
- 使用 QGraphicsOpacityEffect + QPropertyAnimation
- QParallelAnimationGroup 同步位置和透明度动画
- 弹出：220ms OutCubic 滑入+淡入
- 关闭：180ms InCubic 反向滑出+淡出

### 4.7 行为检测

#### 键盘监听（InputMonitor）
- pynput.keyboard.Listener 在 QThread 中运行
- 任意按键按下 → key_pressed 信号（跨线程 Qt queued connection）
- 键盘+鼠标活动 → any_activity 信号（重置 AFK）
- 初始化失败时优雅降级，静默禁用

#### 音频检测（AudioMonitor）
- ctypes 调用 Windows Core Audio API COM 接口
- IAudioMeterInformation.GetPeakValue() 检测音频播放
- IAudioEndpointVolume.GetMute() 检测静音状态
- 500ms QTimer 轮询，边沿触发（仅状态变化时发信号）

### 4.8 Q版交互状态机
```
INACTIVE → STARTUP(序列播放) → IDLE(待机循环) ⇄ INTERACTING(反应播放)
                                    ↕
                               HOVER_IDLE(悬停中)
```
- 启动序列期间交互事件排队
- 双击第二步（哭）不可被打断
- AFK 计时器在进入 IDLE 时启动，任何活动重置

## 5. 性能考量
- PNG 帧图片预加载到内存（默认服装约 14MB）
- GIF 单实例 QMovie，切换文件自动释放旧缓存（~30MB峰值）
- pynput 在后台线程运行，不阻塞 UI
- 音频检测 500ms 轮询，CPU 开销可忽略
