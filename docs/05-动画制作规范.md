# 动画制作规范

## 一、PNG 帧序列（默认服装）

### 文件格式
- **格式**：PNG（支持透明通道）
- **背景**：必须为透明背景
- **文件命名**：三位数字编号 `001.png` `002.png` `003.png` ...
- **编号从 001 开始**，按播放顺序依次编号

### 画面规格
- **推荐比例**：9:16（宽:高），竖长形人像
- **分辨率**：建议单帧高度不低于 800px（保证高分辨率屏幕清晰度）
- **人物应居中**，四周留适当呼吸空间

### 动画时长
- 每个动作的预设播放时长为 **5秒**
- 帧数越多，动画越流畅，帧间隔 = 5000ms ÷ 帧数
- 例子：38帧 → 每帧约131ms，51帧 → 每帧约98ms

### 动画槽位

| 槽位 | 触发条件 | 播放模式 | 说明 |
|------|----------|----------|------|
| **待机动画** | 默认状态（无鼠标交互） | 循环播放 | 桌宠日常待机时的动画 |
| **悬停动画** | 鼠标移入人物区域 | 循环播放 | 鼠标悬停时触发的互动反应 |

### 目录结构

```
assets/
└── {服装名}/
    └── {动作名}/
        ├── 001.png
        ├── 002.png
        └── ...
```

### 添加新动画步骤
1. 制作帧序列PNG，按顺序编号
2. 在 `assets/{所属服装}/` 下新建动作文件夹
3. 将帧文件放入该文件夹
4. 重启桌宠程序即可自动识别

## 二、GIF 动图（Q版高木同学）

### 文件格式
- **格式**：GIF（支持透明背景）
- **背景**：建议透明背景，保证与桌面融合
- **文件命名**：`takagi_{动作名}_{时间戳}.gif`

### 命名规范
程序通过正则表达式自动从文件名提取动作名：
- 模式：`^takagi_(.+)_\d{4}-\d{2}-\d{2}-\d{2}-\d{2}-\d{2}\.gif$`
- 示例：
  - `takagi_唱歌_2026-03-25-23-02-36.gif` → 动作名：`唱歌`
  - `takagi_害羞 2_2026-03-25-19-08-54.gif` → 动作名：`害羞 2`
  - `takagi_打字(普通)_2026-03-25-20-08-01.gif` → 动作名：`打字(普通)`

> 时间戳部分 `_年-月-日-时-分-秒` 必须是文件名末尾，程序自动忽略。

### 画面规格
- **无固定比例要求**，GIF 自动按原始比例显示
- **分辨率**：建议高度不低于 500px
- **帧间隔**：由 GIF 自身帧延迟决定，程序不做统一时长处理

### 目录结构

```
素材库/
└── 高木同学Q版gif/
    ├── takagi_到达_2026-04-03-19-03-56.gif
    ├── takagi_唱歌_2026-03-25-23-02-36.gif
    ├── takagi_害羞 2_2026-03-25-19-08-54.gif
    └── ...（共36个）
```

### 添加新 GIF 步骤
1. 将 GIF 文件按命名规范命名
2. 放入 `素材库/高木同学Q版gif/` 目录
3. 重启桌宠程序 → 新 GIF 自动出现在 Q版设置页的所有下拉框中

### 动画槽位（Q版）

| 槽位 | 触发条件 | 播放模式 |
|------|----------|----------|
| 待机 | 默认状态 | 循环播放 |
| 启动序列 | 程序启动时 | 依次播放（到达→加载→加油） |
| 悬停 | 鼠标移入 | 单次（害羞） |
| 长悬停 | 悬停3秒 | 单次（问号） |
| 单击 | 点击人物 | 单次（惊吓） |
| 双击 | 快速双击 | 链式（生气→哭） |
| 按键 | 任意键按下 | 单次（打字） |
| 音频播放 | 系统输出声音 | 单次（唱歌） |
| 静音 | 系统静音 | 单次（静音） |
| 面板按钮 | 点击面板项 | 单次（点头） |
| 关闭放弃 | 关设置/不保存 | 单次（摇头） |
| AFK随机 | 空闲30秒后 | 单次（从勾选的池中随机） |

### 当前已支持的素材

#### PNG（默认服装）
| 服装 | 动作 | 帧数 | 帧间隔 |
|------|------|------|--------|
| 默认服装 | 默认待机 | 51帧 | ~98ms |
| 默认服装 | 挥手 | 38帧 | ~131ms |
| 默认服装 | 打哈欠 | 30帧 | ~166ms |

#### GIF（Q版高木同学）
共 36 个动图，包括：到达、PNGTuber 加载、加油、害羞、问号、惊吓、生气、哭、点头、摇头、打字(普通)、唱歌、静音、笑、庆祝、点赞、蛋糕、玫瑰、红包、复活节、睡觉(普通)、睡觉(准备阶段1)、汗、主意、冒泡、摇铃、枪、撬棍、拍蝇、喷剂、抓拍(摄像机)、荧光棒、像素墨镜反光、通知提示（爱心/点赞/星星）等。

## 注意事项
- **PNG**：同一服装的所有动作，人物在画面中的位置和大小应保持一致，避免切换动作时出现视觉跳动
- **PNG**：背景务必保持透明，否则桌宠会有难看的背景色块
- **GIF**：文件名必须遵循 `takagi_{动作名}_{时间戳}.gif` 格式，否则无法自动识别
- **GIF**：动作名会直接显示在设置界面中，建议使用直观的中文名称
- **GIF**：透明背景最佳，但即使有背景也能正常显示（无mask穿透）
