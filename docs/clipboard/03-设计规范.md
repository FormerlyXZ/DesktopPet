# 历史粘贴板 - 设计规范

## UI 风格

与现有桌宠设置面板一致：无边框磨砂卡片、淡蓝色调。背景为「壁纸 + 亚克力磨砂叠层」双层渲染，默认不透明白保证文字清晰。

## 配色

| 用途 | 色值 | 说明 |
|------|------|------|
| 亚克力磨砂叠层 | `rgba(255, 255, 255, 0.55)` | 用户可调 0-100（默认 55） |
| 底层壁纸 | 用户上传图 | 完整显示（不单独调透明度） |
| 无壁纸底色 | `rgba(252, 252, 254, 1)` | 不透明白 |
| 边框 | `rgba(187, 222, 251, 0.47)` | 淡蓝半透明 |
| 卡片背景 | `rgba(245, 245, 245, 0.7)` | 浅灰 |
| 卡片悬停 | `rgba(227, 242, 253, 0.8)` | 淡蓝高亮 |
| 主色调 | `#42A5F5` | 蓝色（按钮、选中态） |
| 文字主色 | `#212121` | 深灰 |
| 文字次要 | `#757575` | 中灰 |
| 文字提示 | `#9E9E9E` | 浅灰（时间戳/空状态） |
| 置顶激活 | `#FFA726` | 橙色 |

> 亚克力叠层始终叠加在壁纸之上，保证任何壁纸下文字/卡片都清晰可读。壁纸本身不设透明度滑块（仅亚克力叠层可调）。

## 字体

- 全局：`Microsoft YaHei`，**用户可调 10-20px（默认 13，全局缩放）**
- 标题：比基准略大
- 卡片预览文字：= 基准字号
- 时间戳：基准 - 2px，颜色 `#9E9E9E`

## 窗口规格

- 默认尺寸：560 × 620 px
- 最小尺寸：480 × 400 px
- 圆角：12px
- 标题栏高度 48px（含最小化 / 关闭按钮，上方为拖拽区）
- 工具栏高度：40px

## 正常窗口逻辑

- 窗口标志：`Qt.FramelessWindowHint | Qt.Window`（无边框卡片，但为普通顶层窗口）
- **不再置顶**、**不再使用 Qt.Tool** → 出现在任务栏、可被其他窗口遮挡
- 窗口标题"历史粘贴板"，任务栏显示专属图标

## 专属图标

- 以项目头像（`素材库/高木头像.png`）为底，右下角叠加一个白色剪贴板角标 + 蓝色夹子
- 一键渲染多尺寸（16/24/32/48/64/128/256），由 `_render_icon_pixmap()` / `_make_window_icon()` 生成
- 作为窗口图标（`setWindowIcon`），并在启动时设为**应用级图标 + 设置 Windows AppUserModelID**（`FormerlyXZ.DesktopPet`），确保任务栏正确显示
- 托盘图标仍是主项目头像（粘贴板不新增托盘图标）

## 背景样式（壁纸 + 亚克力叠层）

背景为双层渲染，自下而上：

1. **壁纸背景**：用户上传的本地图片，`cover` 铺满窗口并居中裁剪，完整显示（不单独调透明度）。未上传则跳过本层（无壁纸底色）。
2. **亚克力磨砂叠层**：纯白 `rgba(255,255,255,x)`，按 `acrylic_opacity`（0-100，默认 55）叠加，保证内容可读。
3. **淡蓝描边**：`rgba(187, 222, 251, 0.47)`，1px。

渲染统一由 `_build_background_pixmap(wallpaper, size, acrylic_opacity)` 完成——历史窗口 `paintEvent` 与设置对话框预览复用同一函数，保证所见即所得。

## 壁纸库（缩略图统一管理）

- 历史上传的壁纸**保留**在 `data/clipboard_wallpaper/`，文件名唯一（`wallpaper_{时间戳}_{随机}.ext`），不覆盖
- 设置对话框「背景样式」内新增「壁纸库」：
  - **横向缩略图列表**（`QListWidget` IconMode + LeftToRight，缩略图 72×72，单行横滚）
  - **单击缩略图** → 设为当前壁纸并高亮
  - 「删除选中」→ `QMessageBox` 确认后删除文件；若删除的是当前壁纸则回退默认磨砂底
- 壁纸数无上限，随上传累积，重启保留

## 鼠标缩放（无边框自适应）

- 无边框窗口自身无缩放手柄，需手写：四边（左/右/上/下）+ 四角提供 8px 缩放手柄
- **开启鼠标追踪**（`setMouseTracking(True)`）：鼠标悬停在边缘/角落时立即显示双向箭头光标，无需按键
- 光标映射：左右边 `SizeHorCursor`（↔）、上下边 `SizeVerCursor`（↕）、四角 `SizeFDiag/BDiagCursor`（↖↘ / ↗↙）；移出窗口自动恢复默认箭头（`leaveEvent`）
- 拖动边缘时实时更新几何，最小尺寸钳制为 480×400
- 缩放时排版自适应：文字重新换行、图片等比缩放、滚动条跟随

## 标题栏

- 左侧：📋 历史粘贴板（拖拽区）
- 右侧：「–」最小化（`showMinimized`）、「✕」关闭（淡出隐藏，非退出程序）

## 设置对话框（历史粘贴板设置）

- ⚙ 齿轮按钮打开，尺寸 460×600，圆角 10px
- **背景样式**分区：「选择图片」（拷贝到 `data/clipboard_wallpaper/`，唯一命名）/「清除」+ 亚克力叠层不透明度滑块（0-100）+ **壁纸库缩略图列表** + 缩略预览（410×90）
- **字体大小**分区：QSpinBox 10-20px（默认 13），全局缩放粘贴板所有文字
- **自动清理**分区：保留天数（1-365）+ 一键清除（红色警示）
- 底部：「取消」/「保存」按钮。保存时写入 config.json 并立即生效

## 卡片规格

- 内边距：10px 14px
- 间距：6px
- 圆角：8px
- 置顶卡片：左侧 3px 橙色竖线（`#FFA726`）
- 文字预览最大行数：3（超出截断 + 「展开 ▼ / 收起 ▲」切换）
- 图片最大尺寸：470×350px，等比缩放
- 小图（≤470×350）使用原分辨率，不放大
- 操作按钮尺寸：24×24 px

## 图片卡片布局

图片独占卡片顶部区域，图片下方为按钮行（stretch + 置顶 + 删除）+ 时间戳。

## 工具栏

- 搜索框：圆角 6px，高度 32px，placeholder 颜色 `#BDBDBD`
- 时间筛选按钮：Toggle 样式，选中蓝色，未选中浅灰
- 齿轮按钮：20×20 px，颜色 `#757575`，悬停变 `#424242`

## 空状态

居中显示：
- 图标：📋（48px，颜色 `#BDBDBD`）
- 文字："暂无剪贴板记录"（14px，颜色 `#9E9E9E`）
- 子文字："复制文字或图片后会自动出现在这里"（12px，颜色 `#BDBDBD`）

## 交互反馈

- 卡片点击：复制内容到剪贴板
- 删除按钮悬停：变红色 `#EF5350`
- 置顶按钮：未置顶灰色 `#BDBDBD`，已置顶橙色 `#FFA726`
- 时间筛选按钮：选中蓝色 `#1976D2`，未选中浅灰 `#E0E0E0`
- 时间戳点击：切换绝对时间（`YYYY-MM-DD HH:MM:SS`）↔ 相对时间（"X分钟前"）
- 长文本展开/收起：点击「展开 ▼」/「收起 ▲」
- 一键清除：齿轮设置对话框内红色警示按钮 + QMessageBox 确认
- 托盘右键菜单「历史粘贴板」：直接打开粘贴板窗口；最小化后从托盘/图标再次打开自动还原
