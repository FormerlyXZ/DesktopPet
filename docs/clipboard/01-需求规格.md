# 历史粘贴板 - 需求规格

## 概述
在桌宠软件中集成历史粘贴板功能。用户通过侧边气泡面板打开独立的历史窗口，查看和管理所有已复制的内容（文字和图片），支持搜索、时间筛选、置顶、删除和自动清理。

## 功能需求

### FR-01：剪贴板监控
- 程序启动后自动开始监控系统剪贴板
- 检测文字内容变化：`QClipboard.text()` 非空
- 检测图片内容变化：`QClipboard.image()` 非空
- 连续复制相同内容每次都新增记录（不去重）
- 监控周期：500ms 轮询

### FR-02：数据存储
- 文字内容直接存入数据库
- 图片保存到本地文件系统（`data/clipboard_images/`），数据库存储文件路径
- 存储字段：类型、内容/路径、时间戳、置顶状态

### FR-03：历史窗口入口
- 从桌宠侧边气泡面板"历史粘贴板"按钮打开（激活现有灰色按钮）
- 窗口为独立窗口，可自由拖动、调整大小
- 最小尺寸：480×400，默认尺寸：520×600

### FR-04：卡片列表
- 按时间降序排列（最新在上）
- 置顶卡片始终排在最前
- 每张卡片包含：内容预览、时间戳、置顶按钮、删除按钮
- 文字卡片：显示文字预览（最多 3 行，超出省略）
- 图片卡片：显示缩略图（固定高度 80px，保持原比例）
- 列表为空时显示空状态提示

### FR-05：搜索
- 顶部搜索栏，输入即搜（实时过滤）
- 仅搜索文字内容，不搜索图片
- 大小写不敏感
- 清空搜索框恢复显示全部

### FR-06：时间筛选
- 按钮组：最近 1 天 / 3 天 / 5 天 / 全部
- 默认选中"全部"
- 切换筛选后列表即时刷新
- 筛选与搜索可同时生效

### FR-07：点击复制
- 点击文字卡片 → 将文字内容复制到系统剪贴板
- 点击图片卡片 → 将图片复制到系统剪贴板
- 复制成功后卡片可短暂高亮反馈

### FR-08：置顶与删除
- 每张卡片右上角有置顶按钮（图钉图标）
- 置顶后卡片排到列表最前，且始终在非置顶卡片之上
- 取消置顶后卡片回到正常时间排序位置
- 每张卡片有删除按钮，点击后立即移除记录及关联图片文件

### FR-09：自动清理
- 默认清理超过 7 天的记录
- 用户可在历史窗口内修改清理天数
- 清理同时删除关联的图片文件
- 置顶卡片不受自动清理影响（不删除置顶项）
- 每次启动时执行一次清理检查

### FR-10：配置持久化
- 自动清理天数、字体大小存入 config.json
- 重启后保留用户的这些设置

### FR-11：背景样式（壁纸 + 亚克力叠层）
- 历史窗口背景为「壁纸 + 亚克力磨砂叠层」双层渲染
- 用户可上传本地图片作为背景壁纸（PNG/JPG/JPEG/BMP/WebP）
- 上传后拷贝到 `data/clipboard_wallpaper/`，与原图解耦；未上传则用纯白磨砂底
- 提供「亚克力叠层」不透明度滑块（0-100，默认 55），调节磨砂强弱（壁纸本身不单独调透明度）
- 设置保存在 config.json，重启保留；支持清除壁纸恢复磨砂底

### FR-12：壁纸库（缩略图统一管理）
- 历史上传过的壁纸都**保留**在 `data/clipboard_wallpaper/`，不因更换/重复上传而覆盖
- 设置对话框「背景样式」内新增「壁纸库」：横向缩略图列表，显示所有已上传壁纸
- 单击缩略图 → 设为当前壁纸；当前壁纸高亮
- 「删除选中」→ 确认后从库中移除；若删除的是当前壁纸，则回退到默认磨砂底
- 壁纸数无上限，随上传累积

### FR-13：正常窗口逻辑（任务栏）
- 历史粘贴板从"置顶 + 工具窗"改为**正常窗口**：出现在任务栏、不强制置顶、可被其他窗口遮挡
- 分配**专属窗口图标**（项目头像 + 剪贴板角标叠加），并通过应用级图标 + AppUserModelID 保证 Windows 任务栏正确显示该图标
- 窗口标题为"历史粘贴板"（任务栏可见）

### FR-14：鼠标缩放（无边框自适应）
- 无边框窗口四周边缘 + 四角提供缩放手柄，拖动改变窗口大小
- 缩放时卡片排版丝滑自适应（文字换行、图片等比缩放、滚动条跟随）
- 最小宽高：480×400

### FR-15：字体大小
- ⚙ 设置对话框新增"字体大小"（10-20px，默认 13，全局缩放）
- 作用于卡片预览文字、时间戳、搜索框、按钮等所有文字

### FR-16：最小化
- 标题栏新增"最小化"按钮，点击后最小化到任务栏
- 从托盘/桌面再次打开时自动还原

### FR-17：托盘集成
- 系统托盘**仍只保留主项目一个图标**（不新增粘贴板托盘图标）
- 托盘右键菜单新增"历史粘贴板"选项，可直接打开粘贴板窗口
- 语言切换时该菜单文案同步更新

## 非功能需求

- 剪贴板模块与现有角色系统完全独立，零耦合
- 现有功能（PNG/GIF 角色、行为检测）不得受任何影响
- 无需新增第三方依赖（使用 Python 内置 sqlite3、PySide6 QClipboard 与 winreg）
