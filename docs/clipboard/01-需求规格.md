# 历史粘贴板 - 需求规格

## 概述
在桌宠软件中集成历史粘贴板功能。用户通过侧边气泡面板打开独立的历史窗口，查看和管理所有已复制的内容（文字和图片），支持搜索、时间筛选、置顶、删除和自动清理。

## 功能需求

### FR-01：剪贴板监控
- 程序启动后自动开始监控系统剪贴板
- 检测文字内容变化：`QClipboard.text()` 非空
- 检测图片内容变化：`QClipboard.image()` 非空
- 连续复制相同内容每次都新增记录（不去重）
- 监控周期：500ms 轮询

### FR-02：数据存储
- 文字内容直接存入数据库
- 图片保存到本地文件系统（`data/clipboard_images/`），数据库存储文件路径
- 存储字段：类型、内容/路径、时间戳、置顶状态

### FR-03：历史窗口入口
- 从桌宠侧边气泡面板"历史粘贴板"按钮打开（激活现有灰色按钮）
- 窗口为独立窗口，可自由拖动、调整大小
- 最小尺寸：480×400，默认尺寸：520×600

### FR-04：卡片列表
- 按时间降序排列（最新在上）
- 置顶卡片始终排在最前
- 每张卡片包含：内容预览、时间戳、置顶按钮、删除按钮
- 文字卡片：显示文字预览（最多 3 行，超出省略）
- 图片卡片：显示缩略图（固定高度 80px，保持原比例）
- 列表为空时显示空状态提示

### FR-05：搜索
- 顶部搜索栏，输入即搜（实时过滤）
- 仅搜索文字内容，不搜索图片
- 大小写不敏感
- 清空搜索框恢复显示全部

### FR-06：时间筛选
- 按钮组：最近 1 天 / 3 天 / 5 天 / 全部
- 默认选中"全部"
- 切换筛选后列表即时刷新
- 筛选与搜索可同时生效

### FR-07：点击复制
- 点击文字卡片 → 将文字内容复制到系统剪贴板
- 点击图片卡片 → 将图片复制到系统剪贴板
- 复制成功后卡片可短暂高亮反馈

### FR-08：置顶与删除
- 每张卡片右上角有置顶按钮（图钉图标）
- 置顶后卡片排到列表最前，且始终在非置顶卡片之上
- 取消置顶后卡片回到正常时间排序位置
- 每张卡片有删除按钮，点击后立即移除记录及关联图片文件

### FR-09：自动清理
- 默认清理超过 7 天的记录
- 用户可在历史窗口内修改清理天数
- 清理同时删除关联的图片文件
- 置顶卡片不受自动清理影响（不删除置顶项）
- 每次启动时执行一次清理检查

### FR-10：配置持久化
- 自动清理天数存入 config.json
- 重启后保留用户的清理天数设置

## 非功能需求

- 剪贴板模块与现有角色系统完全独立，零耦合
- 现有功能（PNG/GIF 角色、行为检测）不得受任何影响
- 无需新增第三方依赖（使用 Python 内置 sqlite3 和 PySide6 QClipboard）
