# 历史粘贴板 - 技术方案

## 架构概览

```
main.py
  ClipboardMonitor (QTimer + QClipboard)
      ↓ 写入
  ClipboardStore (sqlite3)
      ↓ 读取
  ClipboardWindow (QWidget)
      ↑ 打开
  PetWindow → BubblePanel
```

剪贴板模块与现有角色系统完全独立，零耦合。

## 核心技术选型

| 组件 | 技术 | 理由 |
|------|------|------|
| 剪贴板检测 | QClipboard + QTimer | PySide6 原生，无需第三方库 |
| 数据存储 | Python sqlite3 | 内置库，支持 SQL 查询和搜索 |
| 图片存储 | 文件系统 | 避免数据库膨胀，路径存 DB |
| UI 框架 | PySide6 QWidget | 与现有代码一致 |

## 模块详细设计

### 1. ClipboardStore（数据层）

**文件**：`src/clipboard_store.py`

**数据库 Schema**：
```sql
CREATE TABLE IF NOT EXISTS clipboard_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    type TEXT NOT NULL,
    text_content TEXT DEFAULT '',
    image_path TEXT DEFAULT '',
    created_at REAL NOT NULL,
    pinned INTEGER DEFAULT 0
);
CREATE INDEX IF NOT EXISTS idx_created_at ON clipboard_history(created_at DESC);
CREATE INDEX IF NOT EXISTS idx_pinned ON clipboard_history(pinned);
```

**接口**：
- `add_text(text: str) -> int` — 添加文字记录，返回 id
- `add_or_update_text(text: str) -> int` — 文字去重：同内容则更新时间戳，否则新增
- `add_image(image_path: str) -> int` — 添加图片记录，返回 id
- `get_items(days: int = 0, search: str = "") -> list[dict]` — 查询（0 = 全部时间）
- `get_by_id(id: int) -> dict | None` — 单条查询
- `pin_item(id: int)` — 切换置顶状态
- `delete_item(id: int)` — 删除记录及关联图片文件
- `clear_all()` — 清除所有非置顶记录及其图片文件
- `cleanup_expired(days: int)` — 清理过期记录
- `get_cleanup_days() -> int` — 获取清理天数设置
- `set_cleanup_days(days: int)` — 设置清理天数

**数据库文件位置**：`data/clipboard.db`

### 2. ClipboardMonitor（监控层）

**文件**：`src/clipboard_monitor.py`

**方案**：QClipboard `dataChanged` 信号 + 200ms 防抖 QTimer
- 先检测图片（`QClipboard.image()`），再检测文字（`QClipboard.text()`）
- 图片优先：浏览器等应用复制图片时剪贴板同时含文字（URL），优先捕获图片
- 图片保存：`QImage.save("PNG")`，失败时回退 `QPixmap.save("PNG")`
- 文字去重：同内容只更新时间戳，不重复插入

**信号**：
- `content_added()` — 有新内容写入时发出（供 UI 实时刷新）

### 3. ClipboardWindow（UI 层）

**文件**：`src/clipboard_window.py`

**窗口属性**：
- `FramelessWindowHint | WindowStaysOnTopHint | Tool`
- `WA_TranslucentBackground`
- 可拖拽移动（重写 mousePressEvent/mouseMoveEvent）
- 可调整大小（默认 520×600，最小 480×400）

**布局结构**：
```
┌─────────────────────────────┐
│ 📋 历史粘贴板            ✕  │  标题栏（拖拽区）
├─────────────────────────────┤
│ 🔍 搜索...  [1天][3天][5天][全部] ⚙│  工具栏
├─────────────────────────────┤
│ ┌─ 文字卡片 ──────────────┐ │
│ │ 📝 文字预览...   📌 🗑   │ │
│ │ 展开 ▼                   │ │  (长文本 >3行时显示)
│ │ 2026-05-26 14:30        │ │
│ └────────────────────────┘ │
│ ┌─ 图片卡片 ──────────────┐ │
│ │                          │ │
│ │     🖼 大图（自适配）     │ │  卡片列表
│ │     最大 470×350px       │ │  (QScrollArea)
│ │                          │ │
│ │              📌 🗑       │ │
│ │ 2026-05-26 12:15        │ │
│ └────────────────────────┘ │
│            ...              │
└─────────────────────────────┘
```

**卡片渲染**：
- 文字卡片：`QLabel` 显示前 3 行文字，超出截断并显示「展开 ▼」
- 图片卡片：直接在卡片中显示大图，最大 470×350px，小图原分辨率不放大

**时间筛选**：
- 计算 `time.time() - days * 86400` 作为起点
- 传入 `get_items(days=...)` 进行数据库过滤

**搜索**：
- `QLabel` 的 `textChanged` 信号实时触发
- 传入 `get_items(search=...)` 进行 SQL LIKE 过滤

**自动清理设置**：
- 工具栏 ⚙ 按钮 → 弹出小对话框
- QSpinBox 选择天数（1-365）
- 保存到 ClipboardStore 设置表

## 数据流

```
用户 Ctrl+C → QClipboard.dataChanged
→ ClipboardMonitor._poll() 检测到变化
→ ClipboardStore.add_text/image()
→ (若窗口打开) content_added 信号 → ClipboardWindow.refresh()
```

```
用户点击卡片 → ClipboardWindow._on_card_click(id)
→ 从 DB 获取内容
→ 文字: QApplication.clipboard().setText()
→ 图片: QApplication.clipboard().setImage()
```
