# 历史粘贴板 - 技术方案

## 架构概览

```
main.py
  ClipboardMonitor (QTimer + QClipboard)
      ↓ 写入
  ClipboardStore (sqlite3)
      ↓ 读取
  ClipboardWindow (QWidget)
      ↑ 打开
  PetWindow → BubblePanel
```

剪贴板模块与现有角色系统完全独立，零耦合。

## 核心技术选型

| 组件 | 技术 | 理由 |
|------|------|------|
| 剪贴板检测 | QClipboard + QTimer | PySide6 原生，无需第三方库 |
| 数据存储 | Python sqlite3 | 内置库，支持 SQL 查询和搜索 |
| 图片存储 | 文件系统 | 避免数据库膨胀，路径存 DB |
| UI 框架 | PySide6 QWidget | 与现有代码一致 |

## 模块详细设计

### 1. ClipboardStore（数据层）

**文件**：`src/clipboard_store.py`

**数据库 Schema**：
```sql
CREATE TABLE IF NOT EXISTS clipboard_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    type TEXT NOT NULL,
    text_content TEXT DEFAULT '',
    image_path TEXT DEFAULT '',
    created_at REAL NOT NULL,
    pinned INTEGER DEFAULT 0
);
CREATE INDEX IF NOT EXISTS idx_created_at ON clipboard_history(created_at DESC);
CREATE INDEX IF NOT EXISTS idx_pinned ON clipboard_history(pinned);
```

**接口**：
- `add_text(text: str) -> int` — 添加文字记录，返回 id
- `add_or_update_text(text: str) -> int` — 文字去重：同内容则更新时间戳，否则新增
- `add_image(image_path: str) -> int` — 添加图片记录，返回 id
- `get_items(days: int = 0, search: str = "") -> list[dict]` — 查询（0 = 全部时间）
- `get_by_id(id: int) -> dict | None` — 单条查询
- `pin_item(id: int)` — 切换置顶状态
- `delete_item(id: int)` — 删除记录及关联图片文件
- `clear_all()` — 清除所有非置顶记录及其图片文件
- `cleanup_expired(days: int)` — 清理过期记录
- `get_cleanup_days() -> int` — 获取清理天数设置
- `set_cleanup_days(days: int)` — 设置清理天数

**数据库文件位置**：`data/clipboard.db`

### 2. ClipboardMonitor（监控层）

**文件**：`src/clipboard_monitor.py`

**方案**：QClipboard `dataChanged` 信号 + 200ms 防抖 QTimer
- 先检测图片（`QClipboard.image()`），再检测文字（`QClipboard.text()`）
- 图片优先：浏览器等应用复制图片时剪贴板同时含文字（URL），优先捕获图片
- 图片保存：`QImage.save("PNG")`，失败时回退 `QPixmap.save("PNG")`
- 文字去重：同内容只更新时间戳，不重复插入

**信号**：
- `content_added()` — 有新内容写入时发出（供 UI 实时刷新）

### 3. ClipboardWindow（UI 层）

**文件**：`src/clipboard_window.py`

**窗口属性（正常窗口逻辑）**：
- `FramelessWindowHint | Qt.Window`（无边框卡片，但为普通顶层窗口）
- `WA_TranslucentBackground`（圆角磨砂）
- **不再置顶**、**不再使用 Qt.Tool** → 出现在任务栏、可被遮挡
- 默认 560×620，最小 480×400；标题"历史粘贴板"，`setWindowIcon(专属图标)`

**背景渲染**：`_build_background_pixmap(wallpaper, size, acrylic_opacity)` 双层渲染：
1. 壁纸图片（若上传），cover 铺满 + 居中裁剪，完整显示（不单独调透明度）
2. 纯白亚克力磨砂叠层，按 `acrylic_opacity`（0-100，默认 55）叠加
3. 淡蓝描边
未上传壁纸则跳过第 1 层（无壁纸底色）。历史窗口 `paintEvent` 与设置对话框预览复用同一函数（所见即所得）。

**专属图标 + 任务栏**：`_render_icon_pixmap(size)` / `_make_window_icon()` 以项目头像为底、叠加剪贴板角标，一键生成多尺寸 `QIcon`。除窗口 `setWindowIcon` 外，在 `main.py` 启动时设为**应用级图标**并调用 `SetCurrentProcessExplicitAppUserModelID("FormerlyXZ.DesktopPet")`，确保 Windows 任务栏正确显示该图标。

**鼠标缩放（无边框手写）**：`_resize_direction(pos)` 判断四边/四角 8px 缩放手柄 → 拖动时 `_perform_resize()` 更新几何，最小尺寸钳制 480×400。开启 `setMouseTracking(True)`，悬停边缘即显示双向箭头光标，移出（`leaveEvent`）自动恢复默认箭头。

**配置键**（config.json `clipboard` 节点）：
```json
"clipboard": {
    "cleanup_days": 7,
    "font_size": 13,
    "wallpaper_path": "",
    "acrylic_opacity": 55
}
```
- `cleanup_days`：自动清理天数（默认 7，存 ClipboardStore 设置表）
- `font_size`：粘贴板全局字体大小（10-20，默认 13）
- `wallpaper_path`：用户上传壁纸路径（拷贝到 `data/clipboard_wallpaper/`），空=无壁纸
- `acrylic_opacity`：亚克力叠层不透明度（0-100，默认 55）；**无壁纸透明度键**

> **持久化**：`config.save()` 为**合并式写盘**（先读已有 `config.json` 再 `deep_merge` 传入 `data`）。因此 `main.py` 退出时的部分保存（不含 `clipboard` 键）不会覆盖历史粘贴板的壁纸/字体设置。

**布局结构**：
```
┌─────────────────────────────┐
│ 📋 历史粘贴板        –  ✕   │  标题栏（拖拽区 + 最小化/关闭）
├─────────────────────────────┤
│ 🔍 搜索...  [1天][3天][5天][全部] ⚙│  工具栏
├─────────────────────────────┤
│ ┌─ 文字卡片 ──────────────┐ │
│ │ 📝 文字预览...   📌 🗑   │ │
│ │ 展开 ▼                   │ │  (长文本 >3行时显示)
│ │ 2026-05-26 14:30        │ │
│ └────────────────────────┘ │
│ ┌─ 图片卡片 ──────────────┐ │
│ │          🖼 大图         │ │  卡片列表
│ │        最大 470×350px     │ │  (QScrollArea)
│ │              📌 🗑       │ │
│ │ 2026-05-26 12:15        │ │
│ └────────────────────────┘ │
│            ...              │
└─────────────────────────────┘
背景 = 壁纸 + 亚克力磨砂叠层
```

**卡片渲染**：
- 文字卡片：`QLabel` 显示前 3 行文字，超出截断并显示「展开 ▼」
- 图片卡片：直接在卡片中显示大图，最大 470×350px，小图原分辨率不放大

**时间筛选**：
- 计算 `time.time() - days * 86400` 作为起点
- 传入 `get_items(days=...)` 进行数据库过滤

**搜索**：
- `QLabel` 的 `textChanged` 信号实时触发
- 传入 `get_items(search=...)` 进行 SQL LIKE 过滤

**字体大小**：
- 基准样式由 `_build_style(font_size)` 生成；`apply_font_size()` 全局刷新并写入 config.json
- 作用于卡片文字、时间戳、搜索框、按钮等

**设置对话框**：
- 工具栏 ⚙ 按钮 → 弹出「历史粘贴板设置」对话框（背景样式 + 字体大小 + 自动清理）
- 背景样式：选择图片 / 清除 + 亚克力叠层不透明度滑块（0-100）+ **壁纸库缩略图列表** + 缩略预览
- 字体大小：QSpinBox 10-20px，保存到 config.json
- 自动清理：QSpinBox 选择天数（1-365），保存到 ClipboardStore 设置表
- 保存后 `apply_background_style()` / `apply_font_size()` 立即生效
- QSpinBox 使用 `SPINBOX_STYLE` 显式定义上/下按键子控件，保证箭头可点

**壁纸库**（`data/clipboard_wallpaper/`）：
- `_copy_wallpaper(src)`：上传图片拷贝入库，文件名唯一（`wallpaper_{毫秒时间戳}_{随机}.ext`），避免覆盖、保留历史
- `_list_wallpapers()`：扫描库目录返回全部壁纸路径（按名称排序）
- `_refresh_library()`：重建横向缩略图 `QListWidget`（QIcon 缩略图 + UserRole 存完整路径），当前壁纸高亮
- `_on_library_clicked(item)`：单击缩略图 → 设为当前壁纸并更新预览/高亮
- `_on_delete_library_item()`：确认后删除文件；若删的是当前壁纸则回退默认磨砂底并刷新

## 数据流

```
用户 Ctrl+C → QClipboard.dataChanged
→ ClipboardMonitor._poll() 检测到变化
→ ClipboardStore.add_text/image()
→ (若窗口打开) content_added 信号 → ClipboardWindow.refresh()
```

```
用户点击卡片 → ClipboardWindow._on_card_click(id)
→ 从 DB 获取内容
→ 文字: QApplication.clipboard().setText()
→ 图片: QApplication.clipboard().setImage()
```
