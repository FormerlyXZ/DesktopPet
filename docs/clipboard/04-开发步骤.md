# 历史粘贴板 - 开发步骤

## 阶段 0：文档准备
1. 创建 `docs/clipboard/` 目录及 4 份文档
2. 更新 CLAUDE.md 添加粘贴板模块指引
3. 更新 devlog

## 阶段 1：数据层 ClipboardStore
1. 创建 `src/clipboard_store.py`
2. 实现数据库初始化（建表、索引）
3. 实现 `add_text()` `add_image()`
4. 实现 `get_items()` 查询（时间筛选 + 搜索）
5. 实现 `pin_item()` `delete_item()`
6. 实现 `cleanup_expired()` 自动清理
7. 命令行测试 CRUD

## 阶段 2：剪贴板监控 ClipboardMonitor
1. 创建 `src/clipboard_monitor.py`
2. 实现 QTimer 轮询 QClipboard
3. 实现文字检测与记录
4. 实现图片检测与图片文件保存
5. 命令行测试监控

## 阶段 3：历史窗口 UI ClipboardWindow
1. 创建窗口骨架（亚克力背景、标题栏、拖拽、调整大小）
2. 实现搜索栏
3. 实现时间筛选按钮组
4. 实现卡片列表渲染（文字 + 图片）
5. 实现点击复制回剪贴板
6. 实现置顶/删除按钮
7. 实现自动清理设置入口
8. 实现空状态

## 阶段 4：集成连线
1. 激活 bubble_panel 灰色按钮
2. pet_window 接收信号创建窗口
3. main.py 初始化 ClipboardMonitor
4. config.py 添加默认配置

## 阶段 5：打磨优化
1. 窗口弹出/关闭动画
2. 图片直接显示在卡片中（大图 470×350px 上限，小图原分辨率）
3. 窗口打开时实时刷新
4. 文字去重（同内容更新时间戳）
5. 置顶可视化（橙色左边框 + 橙色图标）
6. 一键清除按钮
7. 时间戳切换（绝对/相对时间）
8. Tooltip 白底样式
9. 长文本展开/收起
10. 更新 devlog

## 阶段 6：正常窗口 + 缩放 + 字体 + 托盘 + 背景样式
1. 窗口标志改为 `Qt.FramelessWindowHint | Qt.Window`（去掉置顶/`Qt.Tool`），出现在任务栏；`setWindowTitle("历史粘贴板")` + 专属图标
2. `main.py` 启动时设应用级图标 + `SetCurrentProcessExplicitAppUserModelID`，保证任务栏显示专属图标
3. 新增 `_render_icon_pixmap()` / `_make_window_icon()`：项目头像 + 剪贴板角标，生成多尺寸图标
4. 新增无边框鼠标缩放：`_resize_direction()` 判断四边/四角手柄 + `_perform_resize()` 更新几何（最小 480×400）
5. 标题栏新增「–」最小化按钮（`showMinimized`）与「✕」关闭按钮
6. 背景样式（壁纸 + 亚克力叠层）：`_build_background_pixmap(wallpaper,size,acrylic_opacity)`，`config` 含 `wallpaper_path` / `acrylic_opacity`（**无壁纸透明度键**）
7. 设置对话框 = 背景样式（选图/清除 + 亚克力叠层滑块 + 预览）+ 字体大小 + 自动清理
8. QSpinBox 用 `SPINBOX_STYLE` 显式定义上/下按键子控件，修复增大键不可点
9. 托盘右键菜单新增「历史粘贴板」项（`tray_clipboard`），`_on_clipboard` 支持从最小化还原
10. 更新 devlog 与 screenshot / 图标
