## 完成事项

### 🐛 截屏工具产生重复图片

- [x] 修复 Windows 截屏工具（Win+Shift+S / Snipping Tool）截图后粘贴板出现两张相同图片的问题

**根因**：截屏工具将同一图片分两次放入剪贴板（不同格式/不同时机），两次 `dataChanged` 间隔超过 200ms 防抖窗口，导致监控器保存了两张完全相同的图片。

**修复方案**：图片内容哈希去重（类似文字的 `add_or_update_text`）

- 在 `clipboard_history` 表新增 `file_hash` 列，存储图片文件的 MD5 哈希
- 新增 `add_or_update_image()` 方法：5 秒内相同哈希视为重复，更新时间戳并删除新保存的文件
- `ClipboardMonitor._on_debounced()` 保存图片后计算 MD5，调用 `add_or_update_image()` 替代 `add_image()`
- 数据库迁移：`ALTER TABLE` 添加列（已有列则跳过），顺序为「先迁移列 → 后建索引」避免旧库报错

### 修改文件

| 文件 | 改动 |
|------|------|
| `src/clipboard_store.py` | 新增 `file_hash` 列 + 迁移逻辑 + 索引；新增 `add_or_update_image()` 方法；`add_image()` 增加 `file_hash` 参数 |
| `src/clipboard_monitor.py` | 导入 `hashlib`；图片保存后计算 MD5，调用 `add_or_update_image()` |

## 警告修复 + 通用设置 + 语言选项 + .pyw 启动器

### 🐛 QPropertyAnimation 警告修复

- [x] 修复 `QPropertyAnimation::updateState (opacity): Changing state of an animation without target`

**根因**：[panel_animator.py](src/panel_animator.py) 的 `_stop_anim()` 只在 `anim.state() == Running` 时 stop，但始终调用 `widget.setGraphicsEffect(None)`。旧 `QPropertyAnimation` 仍引用已销毁的 target 导致警告。

**修复**：移除状态判断，`anim.stop()` + `anim.clear()` 后先清理子动画再清除特效。

### 🐛 QFont 警告修复

- [x] 修复 `QFont::setPointSize: Point size <= 0 (-1)`

**根因**：QSS 中 `font-family: "Microsoft YaHei"` 不含 emoji 字形，Qt 降级字体时内部生成无效字号。

**修复**：在 `main.py` 中 `QApplication.setFont()` 设置 `families=["Microsoft YaHei", "Segoe UI Emoji", "sans-serif"]`。
