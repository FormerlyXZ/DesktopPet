# 开发日志 - 2026-06-19

## 本日主题：重构点击交互——左键功能面板 + 右键系统面板

## 完成事项

### 交互逻辑重构

- [x] **BubblePanel 重构为可配置项面板**
  - 移除三个硬编码信号（`settings_clicked` / `clipboard_clicked` / `exit_clicked`）
  - 新增统一信号 `item_clicked = Signal(str)`，携带 `item_id`
  - 构造函数改为 `__init__(self, items: list[tuple[str, str]])`，接受动态项列表
  - 菜单项 QLabel 改为动态创建，存入 `self._item_labels: dict[str, QLabel]`
  - `_apply_language()` 和 `eventFilter()` 改为遍历 `_item_labels` 字典

- [x] **PetWindow 双面板 + 右键处理**
  - 左键 → 集成功能面板 `function_panel`（当前仅"历史粘贴板"，后续可扩展）
  - 右键 → 系统面板 `system_panel`（"设置" + "退出"）
  - 新增 `_on_panel_item(item_id)` 统一路由方法
  - `mousePressEvent`：右键也记录按下位置（用于释放时判断是否为点击）
  - `mouseReleaseEvent`：新增右键分支，delta < 5px 触发 `handle_single_click()` + `_toggle_system_panel()`
  - 左右键都触发角色交互动画，差异仅在于弹出哪个面板
  - `_toggle_function_panel()` / `_toggle_system_panel()` 包含互斥逻辑（打开一个时自动隐藏另一个）
  - `mouseMoveEvent`：拖拽时同步移动两个面板
  - `_on_language_changed`：对两个面板都应用语言

## 交互流程

```
左键点击 → handle_single_click() → function_panel (历史粘贴板)
右键点击 → handle_single_click() → system_panel (设置/退出)
双击(GIF)→ handle_double_click() → 不弹面板
拖拽移动 → 移动宠物 + 跟随移动可见面板
```

### 右键系统面板改为鼠标位置弹出

- [x] **BubblePanel 新增 `show_at(pos)` 方法**
  - 接收全局屏幕坐标 QPoint，面板在光标右下 4px 处弹出（类系统菜单习惯）
  - 仅淡入动画（150ms），无滑入位移动画
  - 自动贴边——超出屏幕右/下边界时回缩
  - `_popup_direction` 设为 `"none"` 标记非滑入模式

- [x] **`hide_with_anim` 适配非滑入模式**
  - `_popup_direction == "none"` 时仅淡出（120ms），无位移动画
  - 其他方向保持原有滑入滑出行为

- [x] **`_toggle_system_panel` 改用 `QCursor.pos()`**
  - 从 `popup_at(self.frameGeometry())` → `show_at(QCursor.pos())`
  - 右键系统面板不再出现在桌宠旁边，改为跟随鼠标光标
