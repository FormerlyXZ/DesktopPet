# 开发日志 - 2026-08-12

## 本日主题：修复历史粘贴板筛选"全部"时卡片右侧溢出、按钮消失的问题

---

## 完成事项

- [x] **定位根因** (`src/clipboard_window.py`)
  - 筛选"全部"时 50 条记录全部显示，其中含长文本卡片（无空格的 URL / API key / 文件路径，最长单段 116 字符）
  - QLabel 无法断行 → 文本卡片 sizeHint 膨胀到 **1408px**
  - `widgetResizable=True` 时 QScrollArea 以 `qMax(sizeHint, viewport)` 设置容器宽度 → 容器保持 1408px（视口仅 490px）
  - 横向滚动条被禁用（`ScrollBarAlwaysOff`）→ 全部卡片按 1408px 渲染 → 右侧裁剪
  - 后果：图片居中显示偏右，置顶/删除按钮（卡片最右侧）被裁剪出视口，不可见

- [x] **修复 1：容器宽度锁定为视口宽度**
  - `_list_container.setSizePolicy(QSizePolicy.Ignored, QSizePolicy.Preferred)`
  - 横向策略 Ignored → 忽略子项 sizeHint，容器宽度恒等于视口
  - 文本在卡片内正常换行，不再撑大布局

- [x] **修复 2：图片按实际可用宽度缩放**
  - `_build_image_preview` 中 `max_w` 从硬编码 470 改为 `min(viewport - 24, 470)`
  - 并 `label.setMaximumWidth(max_w)`，窗口较窄或出现纵向滚动条时图片不再溢出卡片
