## 核心文件
| 文件 | 说明 |
|------|------|
| main.py | 程序入口，加载配置，启动桌宠 |
| src/config.py | 配置管理 + 开机自启注册表 |
| src/pet_window.py | 桌宠主窗口（透明、置顶、交互、面板跟随） |
| src/animation.py | 帧动画引擎 |
| src/bubble_panel.py | 侧边气泡面板（亚克力玻璃、图标化菜单） |
| src/settings_window.py | 设置窗口（亚克力玻璃、滑块+数字输入） |
| build.spec | PyInstaller打包配置 |

- 气泡面板：⚙设置 / 📋历史粘贴板(预留) / 🚪退出 + ✕关闭按钮

- 缩放始终从原始帧重绘，无画质损失

- 开机自启（Windows注册表）
