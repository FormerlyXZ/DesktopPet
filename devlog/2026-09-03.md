# 开发日志 - 2026-09-03

## 本日主题：优化历史粘贴板长文字折叠预览——垂直顶对齐

---

## 完成事项

- [x] **定位问题** (`src/clipboard_window.py`)
  - 长文本卡片折叠后只显示约 3 行，用户反馈预览"居中展示"，希望折叠时显示文字**最上面**的部分、点击展开再看全部
  - 根因：预览 `QLabel` 未设置垂直对齐，默认 `AlignVCenter`。在真实 Windows 渲染下，当折叠槽位高于文本绘制区域时，内容会垂直居中摆放（顶部留空隙、起点不贴顶部），观感即"不是从最上面开始"
  - 补充排查：离屏(offscreen)渲染路径对溢出文本恒从顶部裁切，会掩盖该问题，无法用离屏比对复现；改用**真实平台**渲染对比，`AlignTop` 与默认 `AlignVCenter` 的整窗 md5 不同，证明改动真实生效

- [x] **修复：预览文本顶对齐**
  - `_build_card` 中文本预览标签加 `text_preview.setAlignment(Qt.AlignLeft | Qt.AlignTop)`
  - 折叠时 3 行预览从文字最上面开始、紧贴顶部；展开后完整文本从头部开始
