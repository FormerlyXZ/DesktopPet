## 本日主题：修复右键系统面板定位——面板一角对准鼠标（类系统菜单）

---

## 完成事项

- [x] **定位问题** (`src/bubble_panel.py` → `BubblePanel.show_at`)
  - 原实现给面板一个 `+4` 偏移（`pos.x()+4, pos.y()+4`），导致鼠标**落在面板内部**，而不是面板四角之一，与 Windows / 常见软件"面板一角对准光标"的习惯不符
  - 原实现用 `QApplication.primaryScreen()` 做边界判断，多显示器且光标在**副屏**时会在主屏边界上错位夹紧，无法正确限制到光标所在的屏幕
  - 原实现只是"夹紧"（clamp）而不"翻转"（flip）：当光标靠近屏幕右/下边缘时，面板被推到屏幕内，光标就离开了一角，出现一个随机的 gap

- [x] **修复：右上/右下角自适应（类系统菜单定位）**
  - 默认让面板**左上角**对准光标（无偏移）
  - 面板超出屏幕右边界 → 整体翻转到光标**左侧**（右上角对准光标）
  - 面板超出屏幕下边界 → 整体翻转到光标**上方**（左下角对准光标）
  - 两轴同时翻转 → 光标位于面板**右下角**
  - 极端越界兜底：夹紧到该屏幕可用区域（`availableGeometry`）
  - 优先使用**光标所在屏幕**（`app.screenAt(pos) or app.primaryScreen()`），正确处理多显示器

### 修改文件

|------|------|

## 主题三·持久化修复：设置关闭后再打开不丢失

### 问题

历史粘贴板的壁纸、字体等设置关闭后再次打开丢失。

### 根因

`main.py:on_quit` 退出时调用 `save(data)`，传入的 `data` 只含角色/窗口信息，**不含 `clipboard` 键**；而 `config.save()` 直接整写传入字典，导致每次退出都把 `clipboard` 配置（wallpaper / acrylic_opacity / font_size）覆盖丢失。

### 修复

`src/config.py:save()` 改为**合并式写盘**：先读取已存在的 `config.json`，用 `deep_merge` 把传入的 `data` 合并上去（未传入的键如 `clipboard` 保留），再写盘。这样任何一次"部分更新"保存都不会清空其他配置。

### 验证

- 模拟 `on_quit` 部分保存（无 `clipboard` 键）后，`clipboard` 仍完整保留
- 对话框保存后重载配置，壁纸路径 / 字体大小 / 亚克力叠层均持久
- `config.json` `clipboard` 恢复默认，`clipboard.db` 保持干净
