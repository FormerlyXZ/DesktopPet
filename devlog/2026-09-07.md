# 开发日志 - 2026-09-07

## 本日主题：修复右键系统面板定位——面板一角对准鼠标（类系统菜单）

---

## 完成事项

- [x] **定位问题** (`src/bubble_panel.py` → `BubblePanel.show_at`)
  - 原实现给面板一个 `+4` 偏移（`pos.x()+4, pos.y()+4`），导致鼠标**落在面板内部**，而不是面板四角之一，与 Windows / 常见软件"面板一角对准光标"的习惯不符
  - 原实现用 `QApplication.primaryScreen()` 做边界判断，多显示器且光标在**副屏**时会在主屏边界上错位夹紧，无法正确限制到光标所在的屏幕
  - 原实现只是"夹紧"（clamp）而不"翻转"（flip）：当光标靠近屏幕右/下边缘时，面板被推到屏幕内，光标就离开了一角，出现一个随机的 gap

- [x] **修复：右上/右下角自适应（类系统菜单定位）**
  - 默认让面板**左上角**对准光标（无偏移）
  - 面板超出屏幕右边界 → 整体翻转到光标**左侧**（右上角对准光标）
  - 面板超出屏幕下边界 → 整体翻转到光标**上方**（左下角对准光标）
  - 两轴同时翻转 → 光标位于面板**右下角**
  - 极端越界兜底：夹紧到该屏幕可用区域（`availableGeometry`）
  - 优先使用**光标所在屏幕**（`app.screenAt(pos) or app.primaryScreen()`），正确处理多显示器

## 验证

- `python -m py_compile` 对 `bubble_panel.py`、`pet_window.py` 无语法错误
- 定位逻辑自检（屏内坐标几何，`QRect.right()/bottom()` 为含端点坐标）：
  - 默认 `(cursor)` → 左上角对准光标
  - 光标靠近右缘 → `x = cursor.x - width`，右上角对准光标
  - 光标靠近下缘 → `y = cursor.y - height`，左下角对准光标
  - 右+下同时越界 → 右下角对准光标
  - `x = clamp(x, geom.left(), geom.right()-w+1)`、`y = clamp(y, geom.top(), geom.bottom()-h+1)` 保证任意情况下完全落在屏幕内
- 待实机确认：右键系统面板在各屏幕角落均能"一角对准光标"
