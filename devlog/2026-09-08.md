# 开发日志 - 2026-09-08

## 本日主题：Q版夜间睡眠待机——按时段自动切换待机动画

### 需求

23:00-24:00 待机动画自动切换为「睡觉(准备阶段1)」，0:00-6:00 切换为「睡觉(普通)」；其余时段保持用户配置的待机动画。仅影响待机画面，其他交互（悬停/单击/双击/面板/行为检测）照常触发；并在 Q版设置页新增开关与动作选择。

### 完成事项

- [x] **时段解析** (`src/gif_character.py`)
  - 新增 `QTime` 导入与属性：`_sleep_enabled` / `_sleep_prep_action`(=睡觉(准备阶段1)) / `_sleep_normal_action`(=睡觉(普通)) / `_schedule_timer`(每分钟检查一次)
  - `_sleep_key_for_now()`：返回当前时刻应使用的睡眠动作；未启用或无匹配时段返回 None
  - `_resolve_idle_key()`：睡眠时段且该动作在素材库中存在 → 返回睡眠动作；否则回退用户配置的 `_idle_key`（含不存在动作的安全回退）
  - `_on_schedule_tick()`：处于 IDLE 时若目标待机与当前播放不同则切换；切点自动更新
  - `_enter_idle()` / `get_current_pixmap()` 改用 `_resolve_idle_key()`
  - `start()` / `stop()` 启停 `_schedule_timer`
  - `get_settings()` / `apply_settings()` 增补三个睡眠字段（应用时用 `registry.has()` 校验）

- [x] **设置页** (`src/gif_settings_page.py`)
  - 夜间睡眠待机精简为**仅启用开关**（睡眠动画固定为素材库的 `睡觉(准备阶段1)` / `睡觉(普通)`，不再提供下拉框）
  - 开关并入「待机循环」分组（`_build_idle_section`），位于待机动画下拉框下方
  - 移除独立的「夜间睡眠待机」分组、两个睡眠动作下拉框及其 set_actions/load/get 引用

- [x] **多语言** (`src/translations.py`)：`sleep_enable` 保留三语文案；移除不再使用的 `sleep_group` / `sleep_prep_action` / `sleep_normal_action`

- [x] **配置默认值** (`src/config.py`)：`gif` 下新增 `sleep_enabled`(False) / `sleep_prep_action` / `sleep_normal_action`
